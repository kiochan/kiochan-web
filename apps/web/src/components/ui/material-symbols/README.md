# Google Material Symbols

Source: https://github.com/google/material-design-icons/tree/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/symbols/web

The website uses the Rounded, 24px SVG variants. `../material-icon.tsx` embeds their original view boxes and path data, with `currentColor` and decorative accessibility attributes supplied by the website. No icon font, remote stylesheet, or runtime request is required.
