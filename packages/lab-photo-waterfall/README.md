# Photo Waterfall

Photo Waterfall is an original kiochan-web Lab tool based on a user-provided layout sketch. It runs at `/lab/photo-waterfall`. The reference artwork is not bundled.

Add or drop local photos, choose the total canvas width and number of columns, then download a PNG, WebP, or JPG. Each image appears in full at its original aspect ratio, subject to pixel rounding. Equal-width columns share their edges and can differ by one pixel when the canvas width does not divide evenly. The tool automatically balances columns. The preview fits the entire collage by default. Select Scroll to edit to inspect long collages and drag photos within or between columns. Touch screens can drag using a photo's handle, and focused photos can move using the arrow keys. Select Auto arrange to restore automatic balancing. Changing the column count starts a new automatic layout.

Place the spare space at the bottom, at the top, at both ends, or between photos. The last option centers a photo when it is alone in a column. Choose a solid background color for any export or transparent gaps for PNG and WebP. The measured unfilled percentage covers geometric gaps.

Import, layout, preview, and export happen in the browser. The editor generates bounded thumbnails for the editable preview and keeps the original files for export at the requested dimensions. Large PNG exports are encoded in bands to bound working memory for the output canvas. File formats and browser resources determine the practical limits. The layout engine lives in `src/layout.ts`, the editor in `src/index.tsx`, the export entry point in `src/export.ts`, and the independent Lab card preview in `src/preview.tsx`.

Run `node --test scripts/photo-waterfall.test.mjs` and `pnpm --filter @kiochan/lab-photo-waterfall typecheck` from the repository root. Open the Lab route and import mixed portrait and landscape photos. Switch between the overview and scrolling preview, reorder within a column, move between columns, and change gap placement and background. Export all three formats and confirm the dimensions and image bounds match the preview. Check transparent gaps in PNG and WebP and solid fill in JPG. Export a long collage as PNG to exercise the banded encoder.
