# Type Playground

An independent React experiment at /lab/type-playground. Adjust text, typeface, size, and line height. Text remains in component state and resets on reload. No uploads or persistence.

The website owns routes, navigation, metadata, and the shared theme. This package owns controls and scoped CSS. Further development continues here in the Kiochan monorepo.

Run pnpm --filter @kiochan/lab-type-playground typecheck, or pnpm dev at the workspace root to preview.
